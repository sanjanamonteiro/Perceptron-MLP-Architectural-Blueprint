# Perceptron and Multi-Layer Perceptron Architectural Blueprint

## Project Overview
This project implements Perceptron and Multi-Layer Perceptron (MLP) neural network architectures using Python and NumPy in Google Colab.

## Datasets Used
- **Iris Dataset:** Used for binary classification experiments.
- **Handwritten Digits Dataset:** Used for multi-class digit classification.

Both datasets are available through Scikit-learn.

## Experiments Implemented
1. Single-layer Perceptron on the Iris dataset.
2. Multi-Layer Perceptron on the Iris dataset.
3. Multi-Layer Perceptron on the Handwritten Digits dataset.
4. Comparison of activation functions and learning rates.
5. Gradient checking and backpropagation.
6. Early stopping, momentum, and L2 regularization.
7. Model evaluation and training visualizations.

## Technologies Used
- Python
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Results

| Model | Dataset | Test Accuracy |
|---|---|---:|
| Perceptron | Iris | 100% |
| MLP | Iris | 95.24% |
| MLP | Handwritten Digits | 96.99% |

## Output
The implementation generates:
- Training accuracy and loss plots.
- Confusion matrices.
- Digit model weight visualizations.
- Gradient checking results.

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Run all cells from top to bottom.
3. Observe the model training results and generated visualizations.
